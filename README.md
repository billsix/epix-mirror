# ePiX

**ePiX** (pronounced like "epic" with a soft "k", a pun on *TeX*) is a
collection of command-line utilities for \*nix that create mathematically
accurate figures, plots, and movies using easy-to-learn syntax. The output is
expressly designed for use with LaTeX.

The user interface resembles LaTeX itself: you prepare a short *scene
description* in a text editor, then compile the input file into a picture.
LaTeX- and web-compatible output types include a LaTeX `picture`-like
environment written with **PSTricks**, **TikZ**, or **eepic** macros; vector
images (eps, ps, pdf); and bitmap images (png, mng, gif).

## A first figure

```cpp
/* hello.xp */
#include "epix.h"
using namespace ePiX;

int main() {
  picture(P(-1,-1), P(1,1), "2x1in");   // bounding box + physical size
  begin();
    font_size("Huge");
    label(P(0,0), "Hello, world!");
  end();
}
```

Render it with `epix hello.xp` (LaTeX/eepic) or `elaps hello.xp` (eps/pdf).
More worked examples live in [`samples/`](samples/) — see
[`samples/README`](samples/README) for an annotated index.

## The command-line tools

| Tool    | Purpose                                            |
|---------|----------------------------------------------------|
| `epix`  | ePiX → eepic (a LaTeX `picture` environment)       |
| `elaps` | ePiX / eepic → eps or pdf                           |
| `laps`  | (La)TeX → PostScript                                |
| `flix`  | ePiX → png or mng animation                         |

Each script prints a detailed help message when invoked with `-h`. Per-user
options may be set in `~/.epixrc`.

## Installation

ePiX builds with **Meson**:

```sh
meson setup build              # -Dmanual=true to also build the PDF manual
meson compile -C build
meson install -C build
```

Options (see `meson_options.txt`): `epix_el` (install the Emacs mode),
`bash_path`, `runtime_compiler`, `ps2eps`, and `manual`. You need a C++ compiler
(`g++`) to build the library and to compile figures at runtime; the conversion
scripts additionally expect `bash`, `latex`, and `ps2epsi` (or `ps2eps`).

### Containerized build (`Makefile`)

To avoid installing the (large) toolchain on your host, a self-contained
container build is provided via [`Makefile`](Makefile) — a thin
wrapper around `podman` that builds a Fedora image with the full toolchain
(g++, TeX-Live, ghostscript, ImageMagick) baked in. Targets:

```sh
make image                 # build the OCI image
make shell                  # interactive dev shell
make build                  # build libepix.a + driver scripts
make examples               # render samples/+doc/ -> ./output (.eepic)
make examples RENDER=pdf    # ... also render PDFs
make examples-anim          # render .flx animations -> ./output/anim
```

Rendered figures land in `./output/` on the host (bind-mounted into the
container). The build scripts live in [`entrypoint/`](entrypoint/); the image
builds ePiX with Meson. When running nested inside another container, append
`PODMAN_RUN_FLAGS=--cgroups=disabled`.

## Documentation

The full manual lives in [`doc/`](doc/) as LaTeX source (`manual.tex`) and GNU
info (`epix.texi` / `epix.info`). On a normal install it is placed under
`$(prefix)/share/doc/epix` (default `/usr/local/share/doc/epix`). Developer
header files install to `$(prefix)/include/epix`.

## Source layout

The C++ library is `src/*.cc` + public headers in `include/epix/`, all in
`namespace ePiX`, built into the static library `libepix.a`. For a guided tour
— core types (`P`, `Complex`, `Color`), drawing state, geometric objects,
plotting, and the pluggable output backends (`eepic`/`pst`/`tikz`) — see
[`CLAUDE.md`](CLAUDE.md). To add or remove a source file, edit the
`_epix_cc` / `_epix_h` lists in [`meson.build`](meson.build); the umbrella
header `epix.h` is generated by `build-aux/make_header`.
